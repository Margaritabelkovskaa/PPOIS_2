# ♟️ Шахматы на Python

Полнофункциональная шахматная игра с графическим интерфейсом, искусственным интеллектом, онлайн-режимом и анимациями.

![Python Version](https://img.shields.io/badge/python-3.8+-blue.svg)
![Pygame](https://img.shields.io/badge/pygame-2.0+-green.svg)
![License](https://img.shields.io/badge/license-MIT-red.svg)

## ✨ Возможности

- 🎮 **Два режима игры**: локальная игра (2 игрока / против компьютера) и онлайн-игра
- 🤖 **Искусственный интеллект** с 4 уровнями сложности (Easy, Medium, Hard, Expert)
- 🎬 **Анимации**: плавное движение фигур, эффекты взятия, частицы, вспышка при шахе
- 🌐 **Онлайн-режим**: игра по сети через сервер (локальная сеть или интернет)
- 🏆 **Таблица рекордов**: сохранение топ-10 результатов
- 🔊 **Звуки и музыка**: звуки ходов, победы/поражения, фоновая музыка
- 🎨 **Красивый интерфейс**: боковые панели с взятыми фигурами, подсветка ходов

## 🎯 Управление

| Действие | Клавиша |
|----------|---------|
| Выбор фигуры / ход | Левый клик мыши |
| Выход в меню | `ESC` |
| Полный экран | `F11` |
| Выбор фигуры при превращении | `1` (Ферзь), `2` (Ладья), `3` (Слон), `4` (Конь) |
