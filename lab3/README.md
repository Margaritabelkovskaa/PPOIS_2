#  Шахматы

##  Общее описание программы

Программа представляет собой полнофункциональное шахматное приложение с графическим интерфейсом, реализованным на библиотеке Pygame. Поддерживаются три режима игры: локальная игра для двух игроков, игра против искусственного интеллекта (с выбором уровня сложности) и онлайн-игра через локальную сеть.

##  Игровая логика


**Класс ChessPiece:**
- Хранит тип фигуры (P,N,B,R,Q,K), цвет, позицию
- Метод `get_possible_moves()` возвращает все возможные ходы без учёта шаха
- Поддерживает рокировку, превращение пешки, взятие на проходе

**Класс ChessGame:**
- Хранит доску 8×8, очередь хода, список взятых фигур
- `is_check()` — проверяет, находится ли король под шахом
- `is_move_safe()` — проверяет, не подставляет ли ход короля под шах
- `make_move()` — выполняет ход, меняет очередь, проверяет мат/пат
- Очки: 200 − количество ходов (только при победе белых над компьютером)

##  Искусственный интеллект

**Алгоритм:** минимакс с альфа-бета отсечением.

**Принцип работы алгоритма:**

Минимакс — это рекурсивный алгоритм, который моделирует все возможные варианты развития игры на несколько ходов вперёд. ИИ (чёрные) пытается максимизировать свою оценку позиции, а предполагаемый противник (белые) — минимизировать её.

1. **Дерево перебора:** На каждом уровне глубины алгоритм генерирует все возможные ходы для текущего игрока. Чёрные ходы — это уровень максимизации (ищется лучший ход), белые — уровень минимизации (ищется худший для ИИ ход).

2. **Оценочная функция:** Позиция оценивается как сумма ценностей всех чёрных фигур минус сумма ценностей всех белых фигур. Положительная оценка выгодна для ИИ.

3. **Альфа-бета отсечение:** Это оптимизация, которая отсекает ветви дерева, заведомо худшие, чем уже найденные. Альфа — лучший найденный вариант для максимизатора, бета — лучший для минимизатора. Если альфа становится больше или равна бете, дальнейший перебор ветки прекращается.

4. **Рекурсивный спуск:** Алгоритм идёт вглубь до достижения максимальной глубины (заданной сложностью), затем возвращает оценку позиции наверх, где выбирается лучший ход.

**Ценности фигур:**

| Фигура | Ценность |
|--------|----------|
| Пешка | 100 |
| Конь | 320 |
| Слон | 330 |
| Ладья | 500 |
| Ферзь | 900 |
| Король | 10000 |

**Уровни сложности:**

| Сложность | Глубина | Поведение |
|-----------|---------|-----------|
| Easy | 1 | Случайные ходы (имитация слабого игрока) |
| Medium | 2 | Видит на один свой ход и один ход противника |
| Hard | 3 | Видит на 1.5 хода вперёд |
| Expert | 4 | Видит на 2 полных хода вперёд |

**Ограничения текущей реализации:**
- Оценка учитывает только материальную ценность фигур, без позиционных факторов
- Нет таблиц транспозиции (повторные позиции пересчитываются заново)
- Сортировка ходов не используется, что снижает эффективность альфа-бета отсечения

##  Анимации в проекте

| Название анимации | Тип по способу реализации | Описание |
|-------------------|---------------------------|----------|
| `MoveAnimation` | Интерполяционная (Tweening) | Плавное перемещение фигуры из начальной клетки в целевую с использованием ease-out интерполяции `1 - (1 - t)²` |
| `CaptureAnimation` | Трансформационная | Взятая фигура уменьшается в размере (`scale = 1 - t`) и вращается вокруг своей оси (`angle = t * 360`) |
| `Particle` | Физическая (Параметрическая) | При взятии создаются 15 частиц с начальной случайной скоростью, действием гравитации (`vy += 0.5`) и затуханием прозрачности |
| `BoardRotationAnimation` | Композитная (последовательная) | Доска плавно поворачивается на 180° с фиксированным шагом (`ROTATE_STEP = 10°` за кадр) |
| `CompositeAnimation` | Композитная (параллельная) | Одновременное выполнение нескольких анимаций (`MoveAnimation` + `CaptureAnimation` + частицы) с последующей синхронизацией |
| Подсветка выбранной фигуры | Анимация состояния | Вокруг фигуры отображается жёлтая рамка толщиной 3 пикселя при её выборе |
| Подсветка возможных ходов | Анимация состояния | На клетках, куда может сходить фигура, отображаются зелёные круги диаметром в четверть клетки |
| Подсветка шаха | Анимация состояния | При шахе вокруг короля отображается красная рамка толщиной 3 пикселя |
| `PromotionDialog` | Анимация интерфейса | Появление модального окна с выбором фигуры (ферзь, ладья, слон, конь) при превращении пешки |

##  Режимы игры

**Локальная (2 игрока):**
- Игроки ходят по очереди за одним компьютером
- При смене хода доска плавно поворачивается на 180°

**Против компьютера:**
- Игрок играет белыми, компьютер — чёрными
- Выбор сложности: Easy / Medium / Hard / Expert
- После победы игрока начисляются очки: 200 − количество ходов

**Онлайн:**
- Требуется запуск `server.py` в отдельном терминале
- Клиенты подключаются к серверу (localhost:5555)
- Сервер раздаёт цвета (белые первому, чёрные второму)
- Ходы передаются через сокеты с использованием pickle
