##  Лабораторная работа №1

### Вариант 24(Модель умного дома)

Предметная область: автоматизация и управление домашней средой.

Важные сущности: умный дом, умные устройства, системы безопасности, управление освещением, климат-контроль, умные бытовые приборы.

Операции: операция управления освещением и климатом, операция мониторинга систем безопасности, операция управления умными устройствами через мобильное приложение, операция создания расписания автоматизации, операция дистанционного контроля за домом.

**Программа «Модель умного дома»** представляет собой имитационную модель системы автоматизации и управления домашней средой. Она позволяет пользователю управлять различными умными устройствами, настраивать правила автоматизации, контролировать безопасность и дистанционно взаимодействовать с домом через имитацию мобильного приложения.

Проект реализован на языке **Python** с использованием принципов **объектно-ориентированного программирования** и предназначен для запуска в **интерфейсе командной строки (CLI)**.


### Система способна:
Управлять освещением (включение, выключение, регулировка яркости)

Управлять климат-контролем (установка температуры)

Управлять пылесосом (обычная и влажная уборка)

Управлять чайником (кипячение, нагрев воды)

Обеспечивать безопасность (сигнализация с режимами охраны)

Создавать правила автоматизации по времени или статусу устройств
### Реализация операций предметной области 

На основе предоставленного кода были реализованы следующие ключевые операции:

| № | Операция | Реализация в коде |
|---|----------|-------------------|
| 1 | Управление освещением и климатом | Классы `LightDevice` (регулировка яркости, вкл/выкл) и `ClimateDevice` (температура, влажность, режимы, автоподстройка) |
| 2 | Мониторинг систем безопасности | Класс `SecuritySystem` (охрана, снятие с охраны, симуляция тревоги). Уведомления приходят на `OwnerDevice` |
| 3 | Управление через мобильное приложение | Класс `OwnerDevice` — виртуальный телефон. Подключение, отключение, отправка уведомлений |
| 4 | Создание расписания автоматизации | Класс `AutomationRule`. Поддерживаются условия: по времени (`time`) и по статусу устройства (`device_status`) |
| 5 | Дистанционный контроль за домом | Механизм `save_state` / `load_state`. Состояние сохраняется в JSON и восстанавливается при перезапуске

# Умный дом (Smart Home System)

Система управления умным домом с интерфейсом командной строки.

##  Описание классов

###  SmartHome
**Главный класс-контейнер**, содержащий комнаты, устройства, правила и систему безопасности.

**Функции:**
- Хранит все комнаты (`rooms`)
- Хранит систему безопасности (`security_system`)
- Хранит правила автоматизации (`automation_rules`)
- Хранит устройство хозяина (`owner_device`)
- Управляет созданием комнат
- Поиск комнат и устройств
- Проверка правил автоматизации
- Сохранение/загрузка состояния

###  Room
**Представляет комнату** в доме, содержит устройства.

**Функции:**
- Хранит устройства в комнате
- Добавление/удаление устройств
- Поиск устройств по ID
- Поиск устройств по типу

###  SmartDevice (ABC)
**Абстрактный базовый класс** для всех устройств.

**Функции:**
- Общие поля: id, name, room_id, status
- Абстрактный метод `get_device_type()`
- Включение/выключение устройства
- Получение статуса

###  LightDevice
**Конкретная реализация** устройства освещения.

**Функции:**
- Регулировка яркости (0-100%)
- Получение статуса с яркостью

###  ClimateDevice
**Конкретная реализация** устройства климат-контроля.

**Функции:**
- Управление температурой (16-30°C)
- Управление влажностью (30-80%)
- Режимы: auto, cool, heat, dry, fan_only
- Скорость вентилятора
- Автоматическая регулировка

###  SmartCleaner
**Конкретная реализация** умного пылесоса.

**Функции:**
- Режимы: обычный, влажная уборка
- Запуск/остановка уборки

###  SmartKettle
**Конкретная реализация** умного чайника.

**Функции:**
- Кипячение воды
- Нагрев до заданной температуры
- Отслеживание уровня воды

###  SecuritySystem
**Конкретная реализация** системы безопасности.

**Функции:**
- Постановка/снятие с охраны
- Запуск тревоги
- Отслеживание состояния

###  OwnerDevice
**Представляет мобильное устройство** пользователя.

**Функции:**
- Подключение/отключение от системы
- Отправка уведомлений
- Отслеживание последнего доступа

###  AutomationRule
**Содержит условие и список действий**, которые выполняются при его истинности.

**Функции:**
- Условие (`condition`) - время или статус устройства
- Действия (`actions`) - список команд
- Проверка условия
- Выполнение действий
- Включение/отключение правила

### SmartHomeCLI
**Отвечает за взаимодействие с пользователем** через командную строку.

**Функции:**
- Отображение меню
- Управление устройствами
- Создание правил
- Просмотр состояния
- Сохранение/загрузка
# Тестирование программы

В ходе тестирования программы были проверены все основные компоненты системы умного дома. Тестирование проводилось с использованием фреймворка `pytest`. Всего было написано и выполнено **74 теста**, которые покрывают следующие компоненты:  

**1. Классы исключений** — проверена работа всех пользовательских исключений (SmartHomeError, DeviceNotFoundError, RoomNotFoundError, InvalidValueError).

**2. Класс Room** — проверено добавление и удаление устройств в комнате, поиск устройств по ID, поиск устройств по типу.

**3. Базовый класс SmartDevice** — проверено включение и выключение устройств, получение базового статуса.

**4. Класс LightDevice** — проверена установка яркости (0-100%), обработка ошибок при некорректных значениях, получение статуса с яркостью.

**5. Класс ClimateDevice** — проверена установка температуры (16-30°C) и влажности (30-80%), установка диапазонов, увеличение и уменьшение влажности, переключение режимов и скорости вентилятора, автоматическая регулировка, получение полного статуса.

**6. Класс SecuritySystem** — проверена постановка и снятие с охраны, срабатывание тревоги, сброс тревоги.

**7. Класс SmartCleaner** — проверены режимы уборки (обычный и влажный), запуск и остановка пылесоса, обработка неверного режима.

**8. Класс SmartKettle** — проверено кипячение воды, нагрев до заданной температуры, защита от кипячения без воды.

**9. Класс OwnerDevice** — проверено подключение и отключение от системы, отправка уведомлений, получение статуса.

**10. Класс AutomationRule** — проверены условия по времени и по статусу устройства, выполнение действий всех типов (включение, выключение, установка температуры, влажности, яркости, запуск уборки, кипячение, охрана), описание условий и действий, обработка ошибок, отключение правил.

**11. Класс SmartHome** — проверено создание фиксированных комнат, добавление устройства хозяина и сигнализации, поиск комнат и устройств, добавление и удаление правил автоматизации, проверка выполнения правил, получение состояния дома.

**12. Класс SmartHomeCLI** — проверена инициализация, отображение меню, список комнат и устройств, управление освещением, климатом, пылесосом, чайником и сигнализацией, быстрые команды, добавление устройств разных типов, создание правил автоматизации, меню мобильного устройства.

**13. Сохранение и загрузка** — проверена сериализация и десериализация всех типов устройств в JSON.

**14. Интеграционные тесты** — проверен полный жизненный цикл устройства, работа автоматической регулировки климата, цепочка действий с сигнализацией.

## Результат

Все тесты успешно пройдены. Программа работает корректно, ошибок не обнаружено.
