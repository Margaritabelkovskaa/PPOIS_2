# Умный дом - Веб-интерфейс на Django

## Описание проекта

Веб-приложение для управления системой "Умный дом". Предоставляет полный функционал управления устройствами, комнатами, правилами автоматизации и системой безопасности через удобный веб-интерфейс.

## Функциональность

### Управление устройствами
- **Освещение**: включение/выключение, регулировка яркости (0-100%)
- **Климат-контроль**: установка температуры (16-30°C) и влажности (30-80%), выбор режимов работы (auto/cool/heat/dry/fan_only), скорость вентилятора
- **Умный пылесос**: запуск обычной/влажной уборки, остановка
- **Умный чайник**: кипячение, нагрев до заданной температуры

## API Endpoints

### Страницы (HTML)

| Метод | URL | Назначение |
|-------|-----|------------|
| GET | `/dashboard/` | Панель управления |
| GET | `/rooms/` | Список комнат |
| GET | `/security/` | Безопасность |
| GET | `/owner/` | Устройство хозяина |
| GET | `/automation/` | Автоматизация |

### API (JSON)

| Метод | URL | Назначение |
|-------|-----|------------|
| POST | `/api/device/` | Добавить устройство |
| POST | `/api/device/<id>/toggle/` | Вкл/Выкл |
| DELETE | `/api/device/<id>/` | Удалить устройство |
| POST | `/api/device/<id>/brightness/` | Установить яркость |
| POST | `/api/device/<id>/temperature/` | Установить температуру |
| POST | `/api/device/<id>/humidity/` | Установить влажность |
| POST | `/api/device/<id>/mode/` | Установить режим |
| POST | `/api/device/<id>/clean/` | Запустить уборку |
| POST | `/api/device/<id>/boil/` | Вскипятить |
| POST | `/api/security/arm/` | Поставить на охрану |
| POST | `/api/security/disarm/` | Снять с охраны |
| POST | `/api/owner/connect/` | Подключить устройство |
| POST | `/api/owner/disconnect/` | Отключить устройство |
| POST | `/api/owner/notify/` | Отправить уведомление |
| POST | `/api/save/` | Сохранить состояние |
